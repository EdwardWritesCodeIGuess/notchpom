A minimal Pomodoro timer for your Mac menu bar and MacBook notch, now with a Liquid Glass background on macOS 26+ and a frosted fallback on older Macs.

### Download and install

1. Download **NotchPom.dmg** from the assets below. It supports **Apple Silicon and Intel**, on **macOS 13 or later**.
2. Open it and drag **NotchPom** into **Applications**.
3. Eject the disk image and open **NotchPom** from Applications.
4. Click the menu bar countdown, set your Focus and Break times, and press **Start**. There is no Dock icon.

**First launch:** This test build is ad-hoc signed and isn't Apple-notarized. If macOS blocks it, attempt to open it once, then go to **System Settings → Privacy & Security → Open Anyway**, and confirm **Open**. See [Apple's instructions](https://support.apple.com/en-us/102445). Managed Macs may require administrator approval.

No GitHub account, Xcode, or terminal commands needed. A ZIP is also available if you prefer: unzip and drag the app into Applications.

**Updating?** Quit the old app first, then replace it in Applications. Preferences are kept.
